# Reinflate all datablocks from a model Fac object.

Basically a wrapper function for
[`reinflateTensor()`](https://grvanderploeg.com/CMTFtoolbox/reference/reinflateTensor.md)
and
[`reinflateMatrix()`](https://grvanderploeg.com/CMTFtoolbox/reference/reinflateMatrix.md).

## Usage

``` r
reinflateFac(Fac, Z, returnAsTensor = FALSE)
```

## Arguments

- Fac:

  Fac object output from CMTF and ACMTF

- Z:

  Z object as generated by
  [`setupCMTFdata()`](https://grvanderploeg.com/CMTFtoolbox/reference/setupCMTFdata.md).

- returnAsTensor:

  Boolean to return data blocks as rTensor tensor objects (default
  FALSE)

## Value

List of data blocks

## Examples

``` r
set.seed(123)
A = array(rnorm(108*2), c(108, 2))
B = array(rnorm(100*2), c(100, 2))
C = array(rnorm(10*2), c(10, 2))
D = array(rnorm(100*2), c(100,2))
E = array(rnorm(10*2), c(10,2))

df1 = reinflateTensor(A, B, C)
df2 = reinflateTensor(A, D, E)
datasets = list(df1, df2)
modes = list(c(1,2,3), c(1,4,5))
Z = setupCMTFdata(datasets, modes, normalize=FALSE)

result = cmtf_opt(Z, 1, max_iter=2)
Xhats = reinflateFac(result$Fac, Z)
```
