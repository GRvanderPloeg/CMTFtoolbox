# Georgiou2025 Apical Periodontitis data

The Georgiou longitudinal dataset as a three-dimensional array and a
matrix, with subjects in mode 1, features in mode 2, and time in mode3.

## Usage

``` r
Georgiou2025
```

## Format

### `Georgiou2025`

A list object with two elements

- Inflammatory_mediators:

  Longitudinally measured inflammatory mediator data.

- Tooth_microbiome:

  Single-timepoint tooth microbiome data of the extracted tooth
